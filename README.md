# Git Workflow Practice

**WGU D197 · Version Control**

Uses a small company website as practice material for real Git work. The website isn't the point; the Git history is.

## What it shows

- **Branches:** each change is made on its own branch, so the main branch never breaks.
- **Commits:** small commits with messages that explain why, not just what.
- **Merging:** both simple (fast-forward) and full (three-way) merges back into main.
- **Conflicts:** finding and fixing conflicts when two branches change the same lines, without losing work.
- **Remote:** pushing to and pulling from GitHub.
- **History:** using the log and diffs to trace when and why something changed.

## The website

A simple multi-page site for a web design company: home, about, customers and contact pages, with shared CSS, JavaScript and images.

## Files

- `*.html`: site pages
- `css/style.css`: styles
- `js/`: scripts
- `images/`: images
- `retrospective/`: Git log, summary and the written report (PDF)

**Built with:** Git, HTML, CSS, JavaScript
